# Starford International University - Student Portal

Node.js 18+ student portal. No npm install required.

## Run locally (Windows)
- Real portal:  START-PORTAL.bat
- Demo portal:  START-DEMO.bat
- Reset admin:  RESET-ADMIN-PASSWORD.bat  (stop the server first)

Open http://localhost:3000

## Data (never committed)
- ./data/        real data, auto-created
- ./demo-data/   demo data, auto-created
